# Projects

Each folder here is a self-contained Home Assistant project with its own README and
install steps. Grab just the piece you want.

| Project | What it does |
|---|---|
| [**Discogs → Sonos Jukebox**](discogs-jukebox/) | Random record from your Discogs collection on a dashboard tile — tap to play on Sonos, double-tap to shuffle, hold to open Discogs. |
| [**Mailbox Item Tracker**](mailbox-tracker/) | Live count of uncollected items in a remote/CMRA mailbox, counted from the provider's "new mail" emails via IMAP and auto-reset when you collect. |
| [**Nanoleaf Room Clock**](nanoleaf-clock-bar/) | Nanoleaf Lines bar as a linear clock, with an outdoor-temperature gauge, overnight heartbeat, and meeting countdown. AppDaemon app over the local REST API. |

Starting a new one? Copy
[`_template/`](https://github.com/kwilson9/pwnkw_ha/tree/main/projects/_template)
and follow *Adding a new project* in the [root README](../).

> `_template/` is browsable on GitHub but not on this site — Jekyll reserves
> leading-underscore directories and excludes them from the published build.
